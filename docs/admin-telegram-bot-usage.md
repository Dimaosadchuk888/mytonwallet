# Работа с Telegram админ-ботом

Бот доступен только администраторам из `ADMIN_TELEGRAM_IDS` и только в личном
чате. Авторизация проверяется заново для каждого сообщения; наличие кнопки не
даёт дополнительных прав. Не отправляйте боту ключи, seed-фразы или токены.

## Меню

После `/start` или `/help` бот показывает постоянную клавиатуру:

| Кнопка | Действие |
| --- | --- |
| Сводка | Количество пользователей, разрешений, согласий и списаний |
| Пользователи | Список пользователей, по 10 на странице |
| Разрешения кошельков | Активные записи в БД с текущей on-chain проверкой |
| История списаний | Журнал ручных и автоматических списаний |
| Найти пользователя | Запрашивает Telegram ID, затем показывает карточку |
| Баланс пользователя | Запрашивает ID, показывает on-chain USDT отдельно от внутреннего баланса |
| Согласия пользователя | Запрашивает ID, показывает согласия на автосписание |
| Автосписание | Показывает готовность конфигурации и глобальное состояние |
| Ручное списание | Открывает пошаговый предпросмотр без отправки транзакции |
| Состояние системы | Ethereum RPC, ETH для gas, конфигурация и глобальная пауза |
| Остановить автосписание | Включает глобальную остановку новых автосписаний |
| Снять глобальную паузу | Только показывает команду отдельного подтверждения |
| Помощь | Справка |
| Отмена | Закрывает пошаговый ввод, но не отменяет уже отправленные транзакции |

В списках появляются кнопки перехода на соседние страницы. В карточке
пользователя есть кнопки просмотра его баланса и согласий.

## Ручное списание

1. Нажмите **Ручное списание**.
2. Введите Telegram ID пользователя.
3. Выберите связанный кошелёк с активной записью в БД.
4. Введите сумму USDT, например `10.5`, максимум 6 знаков после точки.
5. Выберите получателя из серверного allowlist.
6. Введите причину длиной до 200 символов.
7. Проверьте предпросмотр: пользователь, адреса, сумма, баланс и ограничения.
8. Нажмите **Подтвердить списание …** либо **Отменить списание …**.

Подтверждение действительно 5 минут и только для подготовившего операцию
администратора. Код используется один раз. Отмена предпросмотра закрывает тот же
код без отправки средств. При исполнении разрешение и лимиты проверяются повторно.
Если результат требует проверки, сначала смотрите журнал, не повторяйте списание
вслепую.

Пошаговый ввод хранится в памяти процесса и закрывается после 5 минут
бездействия. После перезапуска/смены экземпляра сервера начните ввод заново либо
используйте полную текстовую команду. Сам предпросмотр и его одноразовое
подтверждение сохраняются в Supabase и не зависят от памяти процесса.

Текстовые команды тоже работают. Telegram не допускает дефис в имени команды
в выпадающем меню, поэтому там используются `/charge_preview`,
`/charge_confirm` и `/charge_cancel`. Старые варианты с дефисом остаются
совместимыми.

## Публикация

При запуске production сервер автоматически регистрирует:

- HTTPS webhook из `ADMIN_BOT_WEBHOOK_URL` с секретом `ADMIN_BOT_WEBHOOK_SECRET`;
- меню Telegram-команд для личных чатов.

Webhook принимает только сообщения: клавиатура отправляет обычный текст, поэтому
обработка `callback_query` не требуется. Если admin token совпадает с основным
wallet bot token, регистрация блокируется, чтобы не перезаписать основной webhook.

После повторной публикации откройте админ-бот и отправьте `/start`. В логах
успешного запуска должны быть сообщения `webhook registered` и
`command menu registered`.

До обеспечения непрерывной работы депозитного монитора глобальную паузу
автосписаний не снимать. Autoscale может останавливать процесс при отсутствии
запросов. Кнопка снятия паузы сама ничего не включает; команда
`/autodebit resume CONFIRM` выполняется отдельно администратором.
