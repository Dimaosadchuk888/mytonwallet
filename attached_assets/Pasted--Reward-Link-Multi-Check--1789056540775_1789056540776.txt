ЗАДАЧА: Reward Link / Multi-Check

Пока ничего не реализовывать. Сначала предложи самый простой и надёжный вариант.

Цель:

Мы хотим создавать специальные ссылки от НАШЕГО TELEGRAM-БОТА, которые можно отправлять людям.

Это должна быть именно Telegram-ссылка/deep link нашего бота, чтобы человек нажимал на неё в Telegram и сразу попадал в наш Telegram Mini App.

Пример логики:

Наш бот
→ специальная ссылка
→ человек нажимает Start / открывает ссылку
→ запускается наш Telegram Mini App
→ система одновременно определяет Telegram-пользователя
→ если аккаунта ещё нет — проходит регистрацию
→ после завершения регистрации применяется награда из ссылки
→ например +1 TON на внутренний баланс.

ВАЖНО:

Это НЕ должна быть просто ссылка:

https://mytonwallet.shop/...

Нам нужна именно ссылка нашего Telegram-бота с параметром/токеном Reward Link, чтобы Telegram передавал этот параметр при запуске Mini App.

Например концептуально:

https://t.me/НАШ_БОТ?start=...

или соответствующий правильный Telegram Mini App deep-link формат.

Точный формат ссылки сначала определи по существующей реализации проекта и Telegram Mini App.

### Простая механика

Администратор создаёт Reward Link:

- reward: 1 TON
- количество получателей: например 100
- уникальный код

Система генерирует Telegram-ссылку.

Мы отправляем её людям.

Человек нажимает ссылку:

Telegram
→ Bot
→ Mini App
→ регистрация/вход
→ проверка Reward Link
→ успешная регистрация
→ +1 TON на Internal Balance.

Если человек уже зарегистрирован — не создавать новый аккаунт, а корректно обработать Reward Link.

Один пользователь не должен получить одну и ту же награду дважды.

### Главное

Не нужно сейчас делать большую систему.

Нам нужен самый аккуратный MVP с минимальным количеством изменений.

Сначала изучи существующий код и ответь только на следующие вопросы:

1. Как сейчас правильно запускать наш Mini App через Telegram-бота?
2. Какой deep-link формат лучше использовать?
3. Как передать через Telegram уникальный Reward Link ID/код?
4. Как связать этот код с регистрацией пользователя?
5. Как после успешной регистрации один раз начислить reward на Internal Balance?
6. Где лучше хранить минимальные данные Reward Link?
7. Как защититься от повторного получения?

После анализа предложи ОДИН рекомендуемый вариант.

Не нужно предлагать 10 архитектур и создавать сложную инфраструктуру.

### Целевой flow

Admin
→ создаёт Reward Link
→ получает Telegram-ссылку
→ отправляет её людям

User
→ нажимает Telegram-ссылку
→ запускается наш бот/Mini App
→ Telegram ID определяется
→ создаётся аккаунт, если его нет
→ пользователь завершает регистрацию
→ система проверяет Reward Link
→ начисляет reward
→ пользователь видит баланс.

Пока НЕ делать:

- код;
- сложную админку;
- blockchain-транзакции;
- реальные отправки TON;
- сложную систему мультичеков;
- дополнительные функции.

Сначала только анализ существующего проекта и предложение самого простого безопасного решения.

Главный принцип:

МИНИМАЛЬНЫЕ ИЗМЕНЕНИЯ → МИНИМАЛЬНОЕ КОЛИЧЕСТВО НОВОЙ ЛОГИКИ → МИНИМУМ ТОЧЕК ДЛЯ ОШИБОК.

После анализа остановись и покажи мне предложенную схему перед реализацией.
