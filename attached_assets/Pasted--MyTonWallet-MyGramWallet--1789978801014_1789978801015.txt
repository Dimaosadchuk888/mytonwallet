4. Особое внимание URL
Нам необходимо очень чётко разделить:
A. URL, которые относятся к бренду
Например:
mytonwallet.io
Такие URL потенциально должны быть заменены на новые URL MyGramWallet.
B. Внешние API
Если endpoint используется как внешний API или сервис, который нельзя менять, НЕ изменяй его автоматически.
Например, если приложение получает курсы валют через внешний API, необходимо определить:
принадлежит ли домен нашему проекту;
является ли он частью бренда;
можно ли его менять;
что сломается при замене.
C. URL, которые нельзя менять
Отдельно составь список URL, которые технически должны остаться без изменений.
Для каждого объясни почему.
